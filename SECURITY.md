# Security Policy

## Scope

This repository contains the source for my personal portfolio at
[nourab.dev](https://nourab.dev). It has no user accounts, no user-submitted
data, and no backend of its own — content is read from a Sanity dataset at
build time.

## Reporting a Vulnerability

Report anything you find to **nour.abshawish@outlook.com**. Please include the
affected URL or file, what you observed, and the steps to reproduce it.

I aim to acknowledge reports within 5 working days. If the issue is valid I
will let you know when a fix is deployed; if I decide not to act on it, I will
tell you why. Please give me a reasonable window to fix an issue before
disclosing it publicly.

## Supported Versions

Only the currently deployed version of the site is maintained. There are no
tagged releases or supported older versions.
